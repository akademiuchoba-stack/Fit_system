
# PROJECT_CONTEXT.md

## Исходные Требования (Задание)
Роль: Вы — Элитный Full-Stack Архитектор и Эксперт по Вычислительной Геометрии (Computational Geometry). Ваша задача — сгенерировать полный, готовый к продакшену код и документацию для системы "Fit_system" (MVP).
Цель: Создать веб-сервис на стеке FastAPI (Python), SQLite и VanillaJS, который парсит данные с O'stin/Lamoda, рассчитывает идеальную посадку одежды с учетом геометрии тела и обучается на основе отзывов.

### Технические Требования
1. **Архитектура**: FastAPI, SQLAlchemy (SQLite), aiohttp, BeautifulSoup4, Tailwind CSS (для визуала).
2. **Парсинг**: Lamoda (INITIAL_STATE), O'stin (Inventory API POST).
3. **Логика**: Вычислительная геометрия (ease, stomach correction, dropped shoulder compensation).
4. **Калибровка**: Байесовское обновление (Normal-Normal Conjugate Prior).
5. **Интерфейс**: Лента карточек, вердикты, детальный сбор фидбека, админка.

### Контекст Окружения
- **Сервер**: Ubuntu 24.04 (IP: 109.73.193.225).
