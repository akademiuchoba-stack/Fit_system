
# PROJECT_CONTEXT.md

## Исходные Требования (Задание)
Роль: Элитный Full-Stack Архитектор и Эксперт по Вычислительной Геометрии.
Цель: Создать систему "Fit_system" (MVP) для ТРЦ «Фестиваль» (Ангарск).

## Архитектурные решения
1. **База данных**: SQLite с включенным режимом WAL.
2. **Хранение**: Изолированная директория `shops/` в корне проекта.
3. **Инициализация**: Автоматическое создание папки и наполнение данными (seeding) при первом запуске.

## Структура проекта
- `backend/`: FastAPI логика, модели, калибровка.
- `frontend/`: UI на VanillaJS + Tailwind.
- `shops/`: Файлы баз данных (SQLite).
- `run.sh`: Единая точка входа для деплоя.
