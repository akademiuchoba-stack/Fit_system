## ПАСПОРТ ПРОЕКТА: «Идеальный Припуск» (MVP)
ПАСПОРТ ПРОЕКТА: «Идеальный Припуск» (MVP)
1. Цель проекта
Создание веб-сервиса для проверки гипотезы алгоритма подбора одежды. Сценарий: Пользователь находится в магазине O'stin (г. Ангарск, ТРЦ «Фестиваль»). Он вводит свои параметры тела, и сервис показывает список товаров из этого конкретного магазина, которые идеально сядут на него, с пояснением (почему подходит/не подходит).

5. Алгоритм «Идеальный Припуск» (Логика)
Функция calculate_match(user, product):

Если есть прямые замеры изделия -> используем их.

Если нет -> восстанавливаем через параметры модели + базовый припуск.

Учитываем эластичность ткани (если эластан > 3%, допускаем меньший припуск).

Генерируем вердикт для каждой зоны (Грудь, Талия, Рост/Рукав): "Идеально", "Туго", "Велико".

Считаем общий total_score (0-5).

Теоретический базис: Полная версия алгоритма «Идеальный припуск».Алгоритм «Идеальный припуск» — это не просто формула сравнения объемов. Это многофакторная вычислительная модель, которая оцифровывает физику посадки изделия, трансформируя субъективное понятие «комфорт» в измеримые математические величины.2.1. Физическая природа припуска (Ease)В основе алгоритма лежит понятие «Припуск на свободное облегание» (Ease Allowance). В конструировании одежды припуск определяется как разница между измерениями готового изделия и измерениями тела человека. Однако, для корректной работы алгоритма необходимо декомпозировать этот показатель на три функциональные составляющие:2.1.1. Технический припуск (Wearing Ease, $E_w$)Это минимально необходимый объем пространства между телом и тканью, обеспечивающий физиологическую жизнедеятельность и подвижность: дыхание, кровообращение, возможность сесть, поднять руки или наклониться.Императив: Если $E_{actual} < E_w$, изделие физически невозможно носить, оно будет сковывать движения или разорвется по швам.Нормативы: Согласно промышленным стандартам, технический припуск варьируется в зависимости от зоны тела. Например, для обхвата груди в классической блузе он составляет 4–6 см, для талии — 2–4 см. Алгоритм жестко кодирует эти пороговые значения как «красные линии», пересечение которых ведет к рекомендации «Не подходит».2.1.2. Дизайнерский припуск (Design Ease, $E_d$)Это дополнительный объем, заложенный модельером для создания определенного силуэта (Silhouette). Именно здесь кроется большинство ошибок при онлайн-покупках: покупатель видит «Оверсайз», но выбирает размер, исходя из своих параметров для «Слим» посадки.Вариативность: Для облегающего платья $E_d$ может быть равен 0, в то время как для худи в стиле «стритвир» $E_d$ может достигать 15–20 см.Роль алгоритма: Система должна распознавать категорию изделия (через API Wildberries или внутренние теги) и применять соответствующий коэффициент $E_d$ к расчетам.2.1.3. Отрицательный припуск (Negative Ease, $E_n$)Этот параметр критичен для трикотажных и эластичных изделий (спортивная одежда, белье, джинсы с эластаном). В данном случае размер изделия в нерастянутом виде меньше параметров тела ($M_{garment} < M_{body}$).Механика: Посадка обеспечивается за счет коэффициента растяжимости ткани (Stretch Factor). Алгоритм должен рассчитывать не статический припуск, а «потенциал растяжения», проверяя, не превышает ли он предел упругой деформации ткани, после которого она деформируется безвозвратно или становится прозрачной.2.2. Математическое ядро алгоритмаПолная версия алгоритма функционирует как последовательность вычислительных этапов, преобразующих входные векторы данных в финальную рекомендацию.Этап 1: Векторизация входных данныхСистема принимает три потока данных:Вектор Тела ($V_{body}$): $ {P_1, P_2,... P_n} $, где $P$ — измерения пользователя (обхват груди, талии, бедер, рост, длина внутреннего шва). Данные могут поступать напрямую от пользователя или через модули компьютерного зрения на базе нейросетей (например, OpenPose или SMPLify-X), восстанавливающие 3D-модель по фото.Вектор Изделия ($V_{garment}$): $ {G_1, G_2,... G_n} $, где $G$ — измерения готового изделия в конкретном размере (S, M, L) в нерастянутом виде. Источником служат оцифрованные лекала (Табели мер).Вектор Материала ($V_{fabric}$): $ {K_{stretch}, K_{recovery}} $, где $K_{stretch}$ — коэффициент растяжимости (например, 1.2 для ткани, тянущейся на 20%).Этап 2: Расчет Эффективного Припуска ($A_{eff}$)Для каждой критической точки измерения (Point of Measure — POM) вычисляется эффективный припуск.Для неэластичных тканей (Woven):$$A_{eff} = G_{pom} - P_{pom}$$Для эластичных тканей (Knits/Stretch):Алгоритм учитывает допустимое растяжение. Если $G_{pom} < P_{pom}$, включается модуль расчета натяжения:$$Tension \% = \frac{P_{pom} - G_{pom}}{G_{pom}} \times 100$$Если $Tension \% \le (K_{stretch} \times W_{comfort})$, где $W_{comfort}$ — коэффициент комфортного натяжения (обычно 50-70% от максимального разрыва), то посадка считается приемлемой. В этом сценарии $A_{eff}$ интерпретируется как степень компрессии.Этап 3: Сравнение с Целевым Диапазоном ($R_{target}$)Для каждого артикула (SKU) в системе задан «Идеальный диапазон припуска» $[Min_{ideal}, Max_{ideal}]$. Это «золотое сечение» посадки.Логика проверки:Если $Min_{ideal} \le A_{eff} \le Max_{ideal}$ $\rightarrow$ Идеальная посадка (Perfect Fit).Если $Min_{tolerance} \le A_{eff} < Min_{ideal}$ $\rightarrow$ Плотная посадка (Slim Fit).Если $Max_{ideal} < A_{eff} \le Max_{tolerance}$ $\rightarrow$ Свободная посадка (Relaxed Fit).Если $A_{eff}$ выходит за пределы $Tolerance$ $\rightarrow$ Не подходит (No Fit).Здесь критически важно понятие Производственного Допуска (Tolerance). В массовом производстве отклонение на +/- 1-2 см считается нормой. Алгоритм «Идеальный припуск» учитывает эту неопределенность, рассчитывая вероятность того, что конкретный экземпляр со склада подойдет пользователю, используя методы статистического анализа (распределение Гаусса вокруг номинального значения размера).
